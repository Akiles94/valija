# Flow: import-chat-history
Summary: export file (.json/.zip) → read + autodetect parser → normalized conversations → select → chunk → `ImportItems` upserts deterministic-id `imported` items in one write tx.
Trigger: CLI `valija import <file>` (`src/delivery/cli/build-program.ts:buildProgram()` → `src/delivery/cli/import-command.ts:importCommand()`); desktop `dialog:chooseImportFile` then `import:list|preview|run` (`desktop/src/main/ipc/handlers/import-handlers.ts:createImportHandlers()`).
Path:
1. Desktop: `desktop/src/main/infra/electron-file-picker.ts:ElectronFilePicker.chooseImportFile()` mints an opaque `fh-N` handle; import channels take only the handle, resolved via `resolveHandle()` (no raw paths over IPC).
2. `src/importers/application/use-cases/import-conversations.use-case.ts:ImportConversations.execute()` — same use case for CLI and desktop.
3. `src/importers/infra/file-export-reader.ts:FileExportReader.read()` — `.zip` inflated in memory (fflate), only `.json` entries, per-entry/total uncompressed caps.
4. `ImportConversations.resolveParser()` — `--from` forces a parser; else first `detect()` in `src/importers/infra/parser-registry.ts:parserRegistry` (`chatgpt`, then `claude`).
5. `ImportConversations.resolveMode()` — no selection flag or `list` → list only; `dryRun` → counts only; else import. `src/importers/domain/services/selection.ts:selectConversations()` then `src/importers/domain/services/chunk-render.ts:renderConversationChunks()`.
6. `src/context/application/use-cases/import-items.use-case.ts:ImportItems.execute()` — one `withSession` + one `session.write()`: find-or-create project, re-validate tags/content per chunk, failures collected, batch never aborts.
7. `src/context/domain/entities/context-item.ts:createImportedContextItem()` — id = sha256(projectId, source, conversationId, chunkIndex) → dedupe via `ON CONFLICT(id)` in `src/context/infra/item-repo.ts:SqliteContextItemRepository.save()`.
Side effects: `context_items` (type `imported`, source `<src>-import`, tags `imported,<src>`), project auto-created, one lineage bump per run (see `.context/flows/multi-device-sync.md`).
Gotchas: re-import overwrites content/tags and resets `pinned` to false on existing ids, but keeps a chunk the user archived archived (`src/context/application/use-cases/import-items.use-case.ts`, CURATION D-H). Dedupe is per project (projectId is in the hash): same export into another project duplicates. `generic` is never autodetected; needs `--from generic`. One malformed `.json` entry in a zip fails the whole read. Epoch-dated conversations get import-time `createdAt`. Selected conversations yielding zero chunks still run the write (project created, lineage bumped). Desktop handles live in an in-memory Map: lost on app restart → `UNREADABLE_FILE` "session expired". Only `import:run` retries `SQLITE_BUSY` (2×200 ms); `import:list|preview` map throws to `STORAGE_ERROR`. CLI exits if a selection flag lacks `-p`.
